# Gym

Front door of Alex & Ziad's gym tracker: https://spartaman1122-hash.github.io/gym/

The app itself runs on Google Apps Script. On an iPhone / iPad home screen, Google's frame forgets the login every time
the app is closed. This page is the home-screen app instead: it shows the Apps Script app in a frame and keeps the login
in its own storage. Nothing else lives here. Source and docs: branch `gym-tracker` of the private repo
`ai-secretary` (`frontdoor/`). Files here are copied from there; change them there first.
